Account boundary

Device ownership, session state, configuration and technical protection verification are separate facts. Account data never substitutes for technical evidence.

Account and device lifecycle actions

Each operation has a separate effect and terminal truth. Completing one must not claim another was completed.

Deleting the account does not remove SafeWeb DNS from a device. Removing SafeWeb DNS does not delete the account, device record, or anonymous web state.
